# Faculty website: Dr. Abul Barkat Mollah Sayeed Ud Doulah

Academic homepage hosted free on GitHub Pages.

| File | What it is | Edit it? |
| --- | --- | --- |
| `content.js` | All website text: bio, research, projects, publications, teaching, service, contact | **Yes, this is the only file you normally edit** |
| `assets/photo.jpg` | Profile photo | Replace with a higher-resolution photo (same file name) |
| `files/` | CV PDF and any other downloads | Upload files here |
| `index.html` | Design and layout | Only for design changes |
| `.nojekyll` | Tells GitHub to serve files as-is | Leave it |

## Publish (one time)
1. Create a free account at github.com. A short username works best, because it becomes the web address.
2. Click **+** (top right) → **New repository**. Name it exactly `USERNAME.github.io` (your username). Choose **Public**. Click **Create repository**.
3. On the empty repository page, click **uploading an existing file**. Drag in everything inside this folder, including the `assets` and `files` folders. Click **Commit changes**.
4. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. After 1–2 minutes the site is live at `https://USERNAME.github.io`.

## Update content
1. Open `content.js` in the repository and click the pencil icon (Edit).
2. Change the text, then click **Commit changes**.
3. Refresh the site after about a minute. Press Ctrl+F5 (Cmd+Shift+R on Mac) if you still see the old version.

If the site goes blank after an edit, there is a typo in `content.js` (usually a missing comma or quote). Open the file's **History**, compare it with the previous version, and fix it.

## Replace the photo
Upload a new image named `photo.jpg` into `assets/` (Add file → Upload files). It replaces the old one. A 4:5 portrait of at least 600 × 750 px looks best.

## Optional
- **Custom domain:** Settings → Pages → Custom domain.
- **Google Search:** add the site in Google Search Console (search.google.com/search-console) using the "URL prefix" option. Then link the site from Google Scholar, ORCID, LinkedIn and ResearchGate.
